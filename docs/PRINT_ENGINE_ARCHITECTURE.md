# Print Engine Architecture

Pilot 3 separates **technical mesh analysis** from **internal CAD** and **commercial quoting**.

## Three layers

| Layer | Location | Role |
|--------|-----------|------|
| **Print core** | `print_core/` | Generic 3MF/mesh parse, volume, bbox, mass helpers. No prices, no customer data. |
| **Aiva3D** | `cad/`, `ui/`, `exporters/`, `projects/work/` | Internal engineering: photo → parameters → CadQuery → validate → export 3MF/STEP/STL. |
| **Crooijmans Quote Engine** | `quote_api/` | 3MF upload → analysis → estimate time → cost → margin → sale price → customer PDF. |

```
                    PRINT CORE
                       │
             ┌─────────┴─────────┐
             │                   │
          Aiva3D          QUOTE API
             │                   │
       internal CAD        commercial
       production           calculation
```

**Dependency rule:** `print_core` never imports Aiva3D. `quote_api` never imports Streamlit, `ui/`, or `projects/work/handle_test`.

## What already exists (reuse patterns, do not duplicate CAD export)

| Asset | Path | Notes |
|--------|------|--------|
| 3MF **export** (write) | `exporters/pipeline.py`, `scripts/export_handle_final.py` | CadQuery → STL tessellation → trimesh. Stays in Aiva3D. |
| Multi-material 3MF scenes | `export_handle_final.py` | `trimesh.Scene`, geometry names `HELFT_*__FILAMENT*_*`. |
| Solid volume (B-rep) | `cad/utilities/validation.py` | `solid_volume()` — CadQuery only. |
| Handle material labels | `projects/work/handle_test/materials.py` | Design legend, not kg pricing. |
| Vercel Crooijmans UI | `web/crooijmans/` | Proxies to `QUOTE_API_URL`. |
| Vercel customer UI | `web/customer/` | `NEXT_PUBLIC_CAD_API_URL` (future CAD API). |

There is **no** existing 3MF **parser** module. Print core uses **trimesh** `load` on `.3mf` (same stack as export).

## What moved into print_core (new)

- `parse_3mf` / `inspect_3mf` — load archive, list mesh objects.
- Volume, surface area, bounding box (mm assumed for Pilot 3).
- Material hints from geometry names and vertex colors (no Crooijmans SKUs).
- `calculate_mass(volume_mm3, density_g_cm3)`.

## What stays Aiva3D-specific

- CadQuery, OpenCascade, Streamlit, FreeCAD bridge, vision/AI.
- `exporters/` write pipeline and `PREVENT_EXPORT_OVERWRITE`.
- All `projects/work/handle_test/` geometry and validation.

## What is new (quote engine)

- FastAPI app under `quote_api/`.
- DEVELOPMENT DEFAULT profiles in JSON (replace with Crooijmans production rates before go-live).
- Estimate print time (not slicer-exact).
- Deterministic pricing engine and customer PDF (no internal cost/margin on PDF).

## Pilot priority

End-to-end chain for Pilot 3:

**3MF → analyse → gewicht → prijs → PDF**

Extended 3MF features can wait until after the calculator works with real Crooijmans files.

## Deployment

| Component | Where |
|-----------|--------|
| Crooijmans UI | Vercel `web/crooijmans` |

| Aiva3D / Streamlit | Internal only |
